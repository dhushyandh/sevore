# Savoré — Contemporary Dining & Café

A contemporary restaurant and café web application crafted with React, TypeScript, Tailwind CSS, and Framer Motion.

## Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run development server:**
   ```bash
   npm run dev
   ```

3. **Build for production:**
   ```bash
   npm run build
   ```
